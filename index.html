04 / SECURITY MODEL

Access is intentional.

The S3 bucket is not the public website endpoint. CloudFront is the viewer-facing entry point, and a scoped bucket policy authorizes the CDN to read objects.

✓Block public ACLsON
✓Ignore public ACLsON
✓Block public bucket policiesON
✓Restrict public bucketsON
s3-bucket-policy.json
{
  "Effect": "Allow",
  "Principal": {
    "Service": "cloudfront.amazonaws.com"
  },
  "Action": "s3:GetObject",
  "Resource": "arn:aws:s3:::<bucket>/*",
  "Condition": {
    "StringEquals": {
      "AWS:SourceArn": ".../distribution/<id>"
    }
  }
}
🔒

Why the SourceArn condition?
It limits this permission to the intended CloudFront distribution rather than granting blanket CDN read access.
